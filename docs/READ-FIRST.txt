NeuroMita.CustomModels — ПРОЧТИ ПЕРВЫМ / READ THIS FIRST
=======================================================

Архив уже содержит нужную структуру папок. Не копируй файлы вручную.


Русский
-------
  1. Сначала установи BepInEx (docs\INSTALL.md, шаг 1).
     Нужна версия 6.0.0-be.788 или новее. После установки запусти игру один раз
     и дай ей сгенерировать interop, потом закрой.

  2. Распакуй этот архив в папку игры — ту, где лежит NeuroMita.exe.
     На вопрос Windows про объединение папок отвечай «Да».

  3. Паки моделей кладутся в CustomModels\, по одной подпапке на пак.
     Чтобы заменить несколько персонажей сразу, используй папки персонажей:
     CustomModels\Crazy\, CustomModels\Kind\ и так далее.

  Полное руководство: docs\INSTALL.md     Проблемы: docs\FAQ.md

  ⚠ Не копируй только часть DLL — нужны все шесть. Без любой из них что-то
    тихо перестанет работать: в частности, без AssetsTools.NET.dll перестают
    грузиться все паки .vrmmod.


English
-------
Do not copy files by hand — the archive already carries the right folder layout.

  1. Install BepInEx (docs\INSTALL.md, step 1). It must be 6.0.0-be.788 or newer.
     Launch the game once afterwards so BepInEx generates its interop assemblies.

  2. Extract this archive into the game folder — the one containing NeuroMita.exe.
     Say yes when Windows asks about merging folders.

  3. Put model packs into CustomModels\, one subfolder per pack. To drive several
     characters at once, use character folders such as CustomModels\Crazy\ or
     CustomModels\Kind\.

  Full guide: docs\INSTALL.md      Troubleshooting: docs\FAQ.md

  All six DLLs are required. Missing one fails quietly — in particular, without
  AssetsTools.NET.dll every .vrmmod pack stops loading.
